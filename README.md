# Nexora Command Center

A portfolio-grade **React + Vite frontend** for a fictional AI-powered product operations platform.

## Why this project is strong for a portfolio

- Responsive SaaS dashboard architecture
- Reusable React components
- Search/filter interaction
- Persistent sidebar + theme preference with localStorage
- Interactive navigation states
- KPI cards with trend indicators
- SVG performance visualization without a chart dependency
- Project portfolio cards with remote image URLs
- Activity feed and notification popover
- Empty/search states
- Mobile responsive layout
- Production build script

## Tech stack

- React
- Vite
- Lucide React icons
- Modern CSS
- LocalStorage
- Remote Unsplash images

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite, normally:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```
