# Portfolio Case Study

## Nexora Command Center — AI Product Operations Dashboard

**Role:** Frontend Developer  
**Type:** Self-initiated portfolio project  
**Stack:** React, Vite, JavaScript, CSS, Lucide React

### Problem
Modern product teams often have project data spread across tools. Nexora presents execution health, project progress, team activity, and AI-generated operational insights in one focused interface.

### What I built
- Responsive command-center dashboard
- Component-driven React architecture
- Persistent dark/light theme
- Searchable project portfolio
- KPI and trend cards
- SVG performance chart
- Activity feed
- Notification interaction
- Responsive sidebar/navigation
- Empty states and secondary module states
- Remote image integration

### Next production steps
Connect a real API, add authentication, server-side search, role-based permissions, real analytics, project CRUD, and route-level code splitting.
